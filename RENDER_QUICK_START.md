# Render Quick Start Checklist

## ✅ Pre-Deployment Checklist

- [ ] Code is pushed to GitHub
- [ ] `render.yaml` is in repository root
- [ ] You have a Render account (sign up at https://render.com)

## 🚀 Deployment Steps

### Option A: Blueprint (Easiest - Recommended)

1. [ ] Go to https://dashboard.render.com
2. [ ] Click **"New +"** → **"Blueprint"**
3. [ ] Connect GitHub and select your repository
4. [ ] Click **"Apply"** - Render will read `render.yaml` automatically
5. [ ] Wait for deployment to complete

### Option B: Manual Setup

1. [ ] Go to https://dashboard.render.com
2. [ ] Click **"New +"** → **"Web Service"**
3. [ ] Connect GitHub repository
4. [ ] **CRITICAL:** Set **Environment** to **PHP** (not Node.js!)
5. [ ] Configure:
   - Name: `portfolio-laravel`
   - Build Command: `composer install --no-dev --optimize-autoloader --ignore-platform-reqs && npm install --legacy-peer-deps && npm run production`
   - Start Command: `php artisan serve --host=0.0.0.0 --port=$PORT`
6. [ ] Click **"Create Web Service"**

## ⚙️ Post-Deployment Configuration

1. [ ] **Set APP_URL:**
   - Go to your service → **Environment** tab
   - Add `APP_URL` = `https://your-app-name.onrender.com` (use your actual URL)

2. [ ] **Run Migrations (if using database):**
   - Go to **Shell** tab
   - Run: `php artisan migrate --force`

3. [ ] **Test Your App:**
   - Visit your app URL
   - Test health check: `https://your-app.onrender.com/health`

## 🔧 Common Issues & Fixes

| Issue | Solution |
|-------|----------|
| "composer: command not found" | Change Environment to **PHP** in Settings |
| Database errors | Check DB environment variables are set correctly |
| 500 Error | Check Logs tab for details, verify APP_KEY is set |
| Assets not loading | Verify `npm run production` completed in build logs |

## 📝 Environment Variables Reference

**Required:**
- `APP_KEY` (auto-generated by Render ✅)
- `APP_URL` (set manually after first deploy)
- `APP_ENV` = `production` (already in render.yaml ✅)
- `APP_DEBUG` = `false` (already in render.yaml ✅)

**Database (if using SQLite - default):**
- `DB_CONNECTION` = `sqlite` (already in render.yaml ✅)
- `DB_DATABASE` = `database/database.sqlite` (already in render.yaml ✅)

**Database (if using PostgreSQL):**
- Uncomment PostgreSQL section in `render.yaml` and redeploy
- Or manually add: `DB_CONNECTION`, `DB_HOST`, `DB_PORT`, `DB_DATABASE`, `DB_USERNAME`, `DB_PASSWORD`
